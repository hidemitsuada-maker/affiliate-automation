# Cocoon 設定チェックリスト（IT転職ナビ）

WP管理画面でこの通りに設定すればOK。上から順に。

## 0. テーマ導入（最初に1回）
- [ ] Cocoon公式から「親テーマ」「子テーマ」両方DL
- [ ] 外観 > テーマ > 新規追加 で両方アップロード
- [ ] **子テーマ（Cocoon Child）を有効化** ← 親を有効化しないこと
- [ ] カスタムCSSは `wp-design/cocoon-custom.css` の中身を
      **Cocoon設定 > カスタムCSS** に全文貼り付け

## 1. Cocoon設定 > スキン
- [ ] スキン = **「シンプル系」or「ビジネス系」** を選ぶ（装飾過多なスキンは避ける／自前CSSと競合させない）
  - 迷ったら「スキンなし」でもOK。自前CSSで見出し等は効く

## 2. Cocoon設定 > 全体
- [ ] サイトフォント = 16px
- [ ] サイトキーカラー = **#0b6fb8**（CSSの--brandと揃える）

## 3. Cocoon設定 > ヘッダー
- [ ] ヘッダーロゴ = サイト名ロゴ画像（無ければテキストロゴでも可）
- [ ] ヘッダーレイアウト = **センターロゴ or 左ロゴ**
- [ ] 高さ控えめ（ファーストビューに本文を入れる）
- [ ] グローバルメニュー = カテゴリ4つを設定（下記4参照）

## 4. メニュー（外観 > メニュー）
グローバルメニューに4カテゴリを並べる（=Pillarへの動線）:
- [ ] 施工管理・現場職から（/construction/）
- [ ] SIer・社内SE（/inhouse-se/）
- [ ] 士業・税理士から（/tax-accountant/）
- [ ] 発達障害・うつから（/vocational-support/）
※各カテゴリのトップに Pillar記事(P1-P4)を割り当てると導線が綺麗

## 5. Cocoon設定 > 目次
- [ ] 目次を表示する = **ON**
- [ ] 表示位置 = 最初のh2の前
- [ ] 表示する見出し = h2・h3
- [ ] 番号表示 = ON

## 6. Cocoon設定 > 本文 / 関連記事
- [ ] 関連記事を表示 = ON（回遊率UP）
- [ ] パンくずリスト = ON（SEO・UX）

## 7. Cocoon設定 > 広告（アフィリエイト運用上の重要設定）
- [ ] **アドセンス等の自動広告は基本OFF**（記事内CTAの邪魔になる／転職アフィはCTA優先）
- [ ] 広告除外は不要なら触らない

## 8. Cocoon設定 > SEO
- [ ] メタディスクリプションの自動生成 = ON（または記事個別に設定）
- [ ] 日付の構造化データ = ON
- [ ] タイトル変更（フロントページ）= 「IT転職ナビ｜未経験からのIT転職を応援」等

## 9. Cocoon設定 > 高速化
- [ ] ブラウザキャッシュ = ON
- [ ] HTML/CSS/JS の縮小化 = 全てON
- [ ] Lazy Load（画像遅延読み込み）= ON
- [ ] ※設定後は必ず表示崩れチェック（崩れたらJS縮小だけOFFで様子見）

## 10. フッター
- [ ] 運営者情報・プライバシーポリシー・免責事項・お問い合わせ へのリンク
  （※アフィ＆E-E-A-T的に **運営者情報とプライバシーポリシーは必須級**。固定ページで用意）

---

## CSS / CTA を貼る場所まとめ
| 何を | どこに |
|---|---|
| `cocoon-custom.css` 全文 | Cocoon設定 > カスタムCSS |
| `cta-parts.html` の①②③ | 再利用ブロック化 → 各記事に差し込み（href差し替え必須） |

## CTAの差し込み位置（推奨）
- 記事の**中盤**（最初の大きな区切りの後）に ② インラインCTA を1つ
- 記事の**末尾**（まとめの後）に ① フルCTAボックス
- Pillar記事の末尾は ③ 複数比較 でもOK

## まだ手付かずの必須固定ページ（E-E-A-T / アフィ規約）
- [ ] 運営者情報（プロフィール）
- [ ] プライバシーポリシー（広告・アフィリエイト・アクセス解析の明記）
- [ ] 免責事項
- [ ] お問い合わせ（Contact Form 7 等）
→ これは中身を俺がドラフト作れる。必要なら言って。
