# keyword-queue/

毎日の記事ドラフト生成に使うキーワードを投入するフォルダ。

## ファイル形式
- ファイル名: `YYYY-MM-DD-001.txt`（日付+連番）
- 内容: キーワード1件（例: `施工管理 転職 未経験`）

## ルール
- 1ファイル = 1キーワード
- 処理済みは `.done` 拡張子に変更される（daily-article-drafterが自動処理）
- 古いファイルから順に処理される

## 例
```
2026-06-06-001.txt  ← 内容: 施工管理 転職 未経験
2026-06-07-001.txt  ← 内容: 社内SE 転職 年収 下がる
2026-06-08-001.txt  ← 内容: 税理士 34歳 転職 遅い
```
